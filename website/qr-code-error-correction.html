QR Code Error Correction Levels Explained

Written by Shahrukh Ahmad — Technical Systems Guide • Last updated October 2026

Key Takeaways

  • QR codes use Reed-Solomon error correction to recover damaged, smudged, or logo-covered data modules.
  • Four levels exist: Level L (~7%), Level M (~15%), Level Q (~25%), and Level H (~30%).
  • When placing a logo in the center, always choose Level Q or Level H so the surrounding parity modules recover the covered area.
  • Higher error correction increases data density, requiring a slightly larger physical print size.

What is Reed-Solomon Error Correction in QR Codes?

Unlike traditional 1D barcodes that fail if a single vertical bar is scratched, QR codes (ISO/IEC 18004 standard) embed mathematical redundancy using Reed-Solomon cyclic error-correcting codes. Redundant data blocks (codewords) are generated through polynomial division over Galois Fields (Galois Field GF(2^8) (256-symbol field)).

When a smartphone camera or scanner captures a damaged or obstructed QR code, the decoder detects error locations and mathematically computes the original payload without needing an external lookup.

The Four Error Correction Levels

The QR code standard defines four standardized error correction levels. Each represents the approximate percentage of codeword modules that can be destroyed or obscured without losing data:

Level Recovery Capacity Redundancy & Density Recommended Use Case
Level L (Low) About 7% of data restored Baseline (Lowest density) Clean digital screens, plain black/white codes with no logo.
Level M (Medium) About 15% of data restored Standard density Default for standard marketing materials, receipts, and flyers without logo.
Level Q (Quartile) About 25% of data restored High density Small logos, outdoor posters, industrial environments exposed to wear.
Level H (High) About 30% of data restored Maximum redundancy Best for custom logos, badges, high-contrast branding, and rugged print use.

Why Level H is Recommended for QR Codes with Logo

When you place an image or corporate icon in the center of a QR code, you physically overwrite the modules located in that central region. The scanner perceives this logo as "damage" or missing data.

With Level H error correction, up to 30% of the entire code matrix can be unreadable, yet the decoding algorithm reconstructs the original link instantly.
